### Install

First download and extract the main `Solar_Colorsoft.zip` file.

*KOReader*

Copy the SVG files from `KOReader/` to the `icons` folder in your KOReader data directory. If the folder doesn't exist, create it. Finally, restart KOReader.

*SimpleUI*

Install `Solar Colorsoft SimpleUI - Install Pack.zip` from **Settings > Style > Icons > Icon Packs > Install pack from ZIP**.
